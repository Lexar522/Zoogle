## 🛒 Можливості для покупця

<details open>
<summary><b>Каталог</b></summary>

- Дерево категорій із сайдбаром і чипами підкатегорій.
- Фільтри за опціями (колір, розмір тощо) і ціною, а також швидкі фільтри «Хіт», «Радимо», «Акція», «Під замовлення».
- Сортування:
  - «Рекомендовані»;
  - ціна ↑/↓;
  - назва А–Я / Я–А;
  - новинки;
  - популярні.
- Живий пошук із підказками.
- Картки товарів у стилі Apple:
  - однакова висота й акуратна сітка;
  - кольорові точки: наведення чи тап показує на картці фото цього кольору;
  - кольорові бейджі «Хіт», «Радимо», «Акція», «Комплект», «Під замовлення»;
  - лайк на фото з лічильником;
  - кнопка «У кошик» прямо з каталогу.
- Спокійна пагінація у стилі Apple.

</details>

<details open>
<summary><b>Сторінка товару</b></summary>

- Єдина галерея: фото товару разом із фото кожного кольору, без дублікатів. Вибір кольору перемикає галерею на його фото.
- Варіанти з власною ціною, залишком і артикулом.
- Рекомендовані та пов'язані товари.
- Блок «Догляд» зі статтями-порадами для категорії.
- Відкладена онлайн-оплата для товарів «під замовлення».

</details>

<details open>
<summary><b>Комплекти</b></summary>

- Каталог комплектів і окремі сторінки комплектів.
- Ціна комплекту зі знижкою та перевірка наявності кожного товару.
- Комплект у кошику займає одну позицію зі зміною кількості.

</details>

<details open>
<summary><b>Кошик і оформлення замовлення</b></summary>

- Висувний кошик на кожній сторінці, вміст зберігається між візитами.
- **Доставка**:
  - Нова Пошта — відділення, поштомат або кур'єр, з пошуком міст, вулиць і відділень через API НП;
  - кур'єр по місту з вибором адреси на карті;
  - самовивіз.
- **Оплата**: LiqPay, WayForPay або при отриманні.
- Окремі правила оформлення для певних категорій.
- Товар резервується під замовлення і повертається на склад при скасуванні або невдалій оплаті.
- Лист-підтвердження з посиланням на відстеження замовлення.

</details>

<details open>
<summary><b>Особистий кабінет</b></summary>

- Реєстрація та вхід через email або Google.
- Історія замовлень і повторна оплата неоплаченого замовлення.
- Обране: товари, відмічені до входу, після входу додаються в кабінет.
- Гість відстежує замовлення за секретним посиланням, яке діє 60 днів.

</details>

<details open>
<summary><b>Контент, мови та SEO</b></summary>

- Сторінки «Про нас», «Контакти», «Доставка й оплата», «Конфіденційність», новини.
- Розділ «Поради» зі статтями про догляд за тваринами.
- Три мови: українська, російська, англійська.
- `sitemap.xml`, `robots.txt`, Open Graph, мікророзмітка Schema.org.
- Фід для Google Merchant, підтримка Google Analytics / Tag Manager і Facebook Pixel.

</details>

## 🧰 Адмінка

Адреса: `/admin`, побудована на Filament 5.

| Розділ | Що можна робити |
|---|---|
| **Товари** | Варіанти, ціни, залишки, фото й відео, фото для кожного кольору, бейджі, SEO |
| **Опції** | Групи та значення: кольори з HEX і фото, розміри |
| **Комплекти** | Набори товарів зі своєю ціною |
| **Акції** | Знижка на товар, варіант чи комплект: відсоток або фіксована ціна, з пріоритетом |
| **Поради** | Статті догляду з прив'язкою до категорій |
| **Замовлення** | Фільтри, зміна статусу, редагування складу з перерахунком сум і залишків, листи покупцю |
| **Сітка каталогу** | Колонки для комп'ютера, планшета й телефона, рядок під назвою, рядки в назві, форма фото |
| **Каталог і головна** | Категорії, шапка каталогу, пагінація, блоки переваг, добірки товарів, футер |
| **Оптимізація медіа** | Зменшені копії фото для швидких карток |
| **Статистика** | Люди онлайн, відвідувачі, виручка, воронка продажів, рейтинг товарів |
| **Інтеграції** | Google Maps, Нова Пошта, WayForPay, точка самовивозу, контакти |

**Ролі**
- 👑 **Адмін** має повний доступ.
- 🧑‍💼 **Менеджер** керує товарами, замовленнями й контентом, але не бачить список покупців, ролі та платіжні ключі.

## 🔒 Безпека

- Лише HTTPS, HSTS, захищені cookie.
- Content-Security-Policy з переліком дозволених джерел скриптів.
- Обмеження частоти запитів на вхід, вхід через Google, оформлення та API.
- Перевірка підписів платіжних callback-ів LiqPay і WayForPay.
- Очищення тексту від небезпечного HTML, безпечні завантаження файлів.
- Права доступу для кожного розділу адмінки.

## 🚀 Локальний запуск

```bash
cd app
composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
npm run build
php artisan serve
```

Тести:

```bash
cd app && php artisan test
```

## 📦 Розгортання

1. Реліз збирається в архів `zoogle-vX.tar.gz` разом із `vendor`, але без `.env` і без завантажених фото.
2. Архів розпаковують поверх папки сайту на хостингу.
3. Після цього виконують:

```bash
php artisan migrate --force   # лише якщо в релізі є міграції
php artisan optimize:clear
php artisan optimize
php artisan filament:optimize
```

Покрокові інструкції для хостингу: [`hosting/BESTHOSTING-UA.md`](hosting/BESTHOSTING-UA.md), [`hosting/DEPLOY-UK.md`](hosting/DEPLOY-UK.md).
