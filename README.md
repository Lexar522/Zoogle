# ZOOGLE — інтернет-магазин зоотоварів

Сайт [zoogle.in.ua](https://zoogle.in.ua) складається з чотирьох частин:
- вітрина з кошиком;
- оформлення замовлення з доставкою Новою Поштою та онлайн-оплатою;
- особистий кабінет покупця;
- адмінка для керування магазином.

Поточна версія: **1.1.59** (див. `app/VERSION`).

| Шар | Технології |
|-----|------------|
| Бекенд | PHP 8.3+, Laravel 13 |
| Адмінка | Filament 5 (Livewire, Alpine.js) |
| Ролі | spatie/laravel-permission (адмін, менеджер) |
| Фронтенд | Blade, Tailwind CSS 4, Vite 8, vanilla JS |
| Вхід | Email або Google (Laravel Socialite) |
| Тести | PHPUnit: 271 тест |

## Можливості для покупця

### Каталог
- Дерево категорій із сайдбаром і чипами підкатегорій, окремі сторінки категорій.
- Фільтри:
  - за опціями (колір, розмір тощо) і ціною;
  - спеціальні фільтри «Хіт», «Радимо», «Акція», «Під замовлення».
- Сортування:
  - «Рекомендовані» (за замовчуванням);
  - за ціною (↑/↓) і за назвою (А–Я / Я–А);
  - новинки та популярні.
- Живий пошук із підказками (`/catalog/suggest`).
- Пагінація у стилі Apple.
- Картки товарів у стилі Apple:
  - усі картки однакової висоти, назва займає задану кількість рядків;
  - кольорові точки варіантів: наведення чи тап показує на картці фото цього кольору;
  - бейджі «Хіт», «Радимо», «Акція», «Комплект», «Під замовлення», «Немає в наявності»;
  - лайк (сердечко) на фото з лічильником;
  - кнопка «У кошик» прямо з каталогу.
- Сітка каталогу (колонки, форма фото, рядок під назвою) налаштовується в адмінці.

### Сторінка товару
- Єдина галерея: усі фото товару разом із фото, прив'язаними до кольорів.
  - Дублікати відкидаються: однаковий шлях або однаковий вміст файлу.
  - Вибір кольору перемикає галерею на фото цього кольору.
- Варіанти з власною ціною, залишком і артикулом.
- Рекомендовані та пов'язані товари.
- Блок «Догляд» зі статтями-порадами для категорії.
- Відкладена онлайн-оплата для товарів «під замовлення».

### Комплекти
- Каталог комплектів і окремі сторінки комплектів.
- Ціна комплекту зі знижкою та перевірка наявності кожного товару.
- Комплект у кошику займає одну позицію зі зміною кількості.

### Кошик і оформлення
- Висувний кошик на кожній сторінці. Вміст зберігається між візитами.
- Доставка:
  - Нова Пошта: відділення, поштомат, кур'єр. Пошук областей, міст, вулиць і відділень працює через API НП;
  - кур'єр по місту з вибором адреси на карті (Leaflet + геокодування);
  - самовивіз із точкою на карті.
- Окремі правила оформлення для певних категорій.
- Оплата:
  - онлайн через LiqPay або WayForPay, callback-и перевіряються за підписом;
  - або при отриманні.
- Залишки резервуються під замовлення і повертаються при скасуванні чи невдалій оплаті.
- Лист покупцю з підтвердженням і посиланням на відстеження.

### Акаунт
- Реєстрація та вхід через email або Google.
- Історія замовлень і повторна оплата неоплаченого замовлення.
- Обране: після входу додається й те, що відмітили до входу.
- Редагування профілю.
- Гість бачить своє замовлення за секретним посиланням.
  - Посилання діє 60 днів.
  - Після першого відкриття токен зникає з адресного рядка.

### Контент і мови
- Сторінки: «Про нас», «Контакти», «Доставка й оплата», «Конфіденційність», інфосторінки, новини.
- Розділ «Поради» (`/porady`) зі статтями про догляд.
- Три мови: українська, російська, англійська.

### SEO та маркетинг
- `sitemap.xml`, `robots.txt`, canonical, Open Graph, мікророзмітка Schema.org (JSON-LD).
- Фід Google Merchant (`/feeds/google-merchant.xml`).
- Підтримка Google Analytics / Google Tag Manager і Facebook Pixel.

## Адмінка (`/admin`)

### Каталог
- **Товари**:
  - варіанти, опції, ціни, залишки;
  - фото й відео товару та окремі фото для кожного кольору;
  - бейджі та SEO-поля.
- **Групи опцій** і **значення опцій**: кольори з HEX і фото, розміри, взаємовиключні групи.
- **Комплекти**.
- **Акції**:
  - на що діє: товар, варіант або комплект;
  - знижка у відсотках або фіксованою ціною;
  - пріоритет між акціями.
- **Статті догляду** (Поради) з прив'язкою до категорій.
- **Категорії каталогу**, **шапка каталогу** (чипи, контакти), **пагінація**.
- **Сітка каталогу**:
  - колонок на комп'ютері (3–5), планшеті (2–4), телефоні (1–2);
  - рядок під назвою: кольори, категорія або нічого;
  - рядків у назві: 1–3;
  - форма фото: 1:1, 4:5 або 4:3.

### Головна та оформлення
- Блоки переваг, добірки товарів на головній, футер.
- **Оптимізація медіа**: зменшені копії фото для карток.

### Замовлення
- Список із фільтрами, віджети підсумків.
- Редагування складу замовлення з перерахунком сум і залишків.
- Статуси: нове → оплачено → в обробці → відправлено → виконано / скасовано.
- Листи покупцю при зміні статусу.

### Статистика та інтеграції
- **Статистика сайту**:
  - люди на сайті зараз;
  - відвідувачі й перегляди;
  - виручка й замовлення;
  - воронка продажів;
  - рейтинги товарів.
- **Інтеграції**:
  - ключі Google Maps і Нової Пошти;
  - WayForPay і вибір онлайн-оплати;
  - точка самовивозу, контакти в шапці.

### Ролі
- **Адмін** має повний доступ, разом із користувачами та інтеграціями.
- **Менеджер** керує товарами, замовленнями й контентом. Він не бачить списку покупців, ролей і платіжних ключів.

## Безпека
- Лише HTTPS, HSTS, cookie з прапорами `Secure` / `HttpOnly` / `SameSite`.
- Content-Security-Policy зі списком дозволених джерел скриптів та `frame-ancestors 'self'`.
- Обмеження частоти запитів на вхід, Google OAuth, оформлення та API-ендпоінти.
- Перевірка підписів callback-ів LiqPay і WayForPay.
- Очищення rich-text від небезпечного коду.
- Безпечні завантаження: лише фото й відео, імена файлів випадкові.
- Права доступу в адмінці задаються політиками (Policies) для кожного ресурсу.

## Локальний запуск

```bash
cd app
composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
npm run build
php artisan serve
```

Тести:

```bash
cd app && php artisan test
```

## Розгортання

Реліз збирається в архів `zoogle-vX.tar.gz`. Він містить `vendor`, але не містить `.env` і завантажених фото. Архів розпаковують поверх папки сайту на хостингу, а потім виконують:

```bash
php artisan migrate --force   # лише якщо в релізі є міграції
php artisan optimize:clear
php artisan optimize
php artisan filament:optimize
```

Інструкції для BestHosting: `hosting/BESTHOSTING-UA.md` і `hosting/DEPLOY-UK.md`.
